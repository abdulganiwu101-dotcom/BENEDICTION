# Public Static Assets

This directory contains static assets served directly at the root URL path.

## Planned Subdirectories:
- `images/`: High-resolution personal profile pictures, portfolio project screenshots, and brand assets.
- `icons/`: Static icon files, vector marks, and web clip icons.
- `documents/`: Downloadable documents (e.g., Curriculum Vitae / Resume in PDF format).
- `favicon/`: Browser tab favicons (`favicon.ico`, `favicon-32x32.png`, `apple-touch-icon.png`, `site.webmanifest`).
