# Bundled Assets (`src/assets`)

This directory houses static assets that are imported directly into JavaScript/TypeScript/CSS files and bundled/optimized by Vite during the build step.

## Subdirectories:
- `images/`: Optimized image assets (e.g. SVG graphics, WebP images).
- `icons/`: Custom vector icons that are not part of the standard icon set.
- `fonts/`: Self-hosted web fonts (if custom typography is introduced in Segment 2).
