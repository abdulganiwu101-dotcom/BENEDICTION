# Portfolio Sections (`src/sections`)

This directory contains the individual high-level sections that assemble the portfolio page.

## Implemented Sections:
- `Hero/`: Introduces Benediction, his status as a Computer Science student, availability badge, action triggers, and social link strip (Segment 4).
- `About/`: Authentic biographical narrative, Accra Technical University educational card, mindset & approach pillars, and guiding perspective quote (Segment 5).
- `Skills/`: Skills & Technologies section featuring 4 categories (Programming, Web Development, Tools & Workflow, Technical Foundations) (Segment 6).
- `Projects/`: Projects & Experiments section presenting 3 authentic project initiatives (Kintampo Rural Bank, Benelodge, Hi5 Pub & Grills) with truthful status badges and zero fabricated links (Segment 7).
- `Experience/`: Experience & Learning Journey timeline section tracking 4 developmental milestones (Building My Foundation, Turning Knowledge into Skills, An Idea for Student Accommodation, Growing into a Software Developer) (Segment 8).
- `Contact/`: Contact section featuring verified contact credentials, direct email dispatch, and an accessible form with inline validation (Segment 9).

## Conventions:
- Every section is bound to its intended HTML anchor ID (`id="home"`, `id="about"`, `id="skills"`, `id="projects"`, `id="experience"`, `id="contact"`).
- Content is strictly driven by typed data structures located in `src/data/`.
