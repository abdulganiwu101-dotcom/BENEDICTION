# Styles & Design Tokens (`src/styles`)

This directory houses global CSS definitions, custom Tailwind layers, design tokens, and typography configurations established in Segment 2.

## Key Files:
- `theme.ts`: Strongly typed constants for color palettes (brand, accent, neutral, surface), typography scale, layout containers, and shadow tokens.
- `src/index.css`: Tailwind CSS v4 `@theme` block, semantic CSS variables, base body typography, `.portfolio-container`, `.portfolio-section`, and `.focus-ring` utilities.
