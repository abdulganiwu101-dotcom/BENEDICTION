# Source Directory (`src`)

This directory contains the application's source code, components, sections, data models, and styles.

## Subdirectories:
- `assets/`: Processed static assets (images, icons, fonts) imported directly in TypeScript/CSS files.
- `components/`: Atomic and composite UI components (buttons, badges, modals, cards).
- `sections/`: High-level portfolio sections (Hero, About, Skills, Projects, Experience, Contact).
- `pages/`: Page-level components.
- `styles/`: Additional styling definitions, animations, and Tailwind layer customizations.
- `data/`: Typed data schemas and user content (projects, experience, skills, personal profile).
- `utils/`: Reusable helper functions, formatters, and validation routines.

## Core Files:
- `App.tsx`: Top-level orchestrator.
- `main.tsx`: React DOM mount point.
- `index.css`: Global Tailwind CSS imports and theme configuration.
